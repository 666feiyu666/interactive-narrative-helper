# Interactive Narrative Helper

Interactive Narrative Helper is an in-progress research project on evidence-grounded, human-controlled support for educational interactive narrative design. Current work is defining the screening, coding, and analysis method for the retained public itch.io source-preparation outputs while preserving a separate long-term inquiry into author-controlled story-level narrative technique support; the repository remains under active research development, and its structure, methods, and implementations may change before the next milestone.
