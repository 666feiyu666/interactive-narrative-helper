# Learning to Design Projects from Design Projects

Interactive Narrative Helper is an in-progress research program on human-controlled design support for Interactive Fiction. Current work is on Track A: source acquisition and deterministic cleaning are complete for 606 public itch.io candidate pages, and the next work is to design the screening, coding, and analysis method for their creator descriptions. Track B remains a later story-level narrative-technique direction, with counterfactual action and consequence as its only specified technique. See more from [`research/program-overview.md`](research/program-overview.md).
