# Design briefs

This directory holds author-reviewed, case-specific instances of the broader
Educational Interactive Narrative Design Brief concept. A brief may carry a
selected macro direction into the Fox-and-Crow task by adding a target age,
educational purpose, application setting, interaction pattern, values, or
other constraints.

Every brief should reference the stable case ID, distinguish sourced facts from
author choices, and must not overwrite the base case silently. These briefs are
Track B task inputs; they are not evidence that the future Track A Helper or a
fixed bridge schema has been implemented.
