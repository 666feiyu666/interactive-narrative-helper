# Display prompt

`design-advisor.md` is the single prompt used by the live display mode. It
asks for a Chinese diagnosis, exactly three materially different directions,
one to three selected case IDs, a prototype step, and at most one follow-up
question. The local server—not the model—adds public titles and links.

The supplied records are display fixtures. This prompt is not a formal Agent
model, experimental condition, or evidence that the proposed capability works.
