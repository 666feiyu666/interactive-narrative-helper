# Legacy components

This directory preserves predecessor implementations so their code, assumptions,
and Git history remain available for comparison.

`theory-guided-story-generator/` is the earlier five-section DeepSeek story
generator. It uses explicit theory-derived structure and human acceptance of
each generated section. It predates the current counterfactual narrative design
RQ and must not be described as a validated baseline until both systems receive
comparable tasks and evaluation criteria.
