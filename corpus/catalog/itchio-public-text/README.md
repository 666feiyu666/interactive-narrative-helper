# itch.io educational-IF candidate inventory

`manifest.json` is generated by following the public pagination of the itch.io
`Educational + Interactive Fiction` listing. It freezes URL order, listing page,
listing position, discovery title, timestamp, and the result count displayed at
discovery time.

The manifest contains no copied project-page descriptions. Full rendered text
belongs only in the Git-ignored `corpus/restricted-sources/itchio-public-text/`
directory.

The 606 entries are candidates discovered through one platform-tag
intersection. They have not all been screened for educational relevance,
observable IF mechanics, evidence availability, or rights. The manifest must
not be described as a confirmed educational-IF corpus.

The explicitly authorized 606-entry stable acquisition is summarized in
[`acquisition-run-full-001.md`](acquisition-run-full-001.md). Its restricted
payloads are the current acquisition evidence. Completion of this run does not
turn the candidate inventory into a screened corpus.

The deterministic offline cleaning of those 606 captures is summarized in
[`cleaning-run-full-001.md`](cleaning-run-full-001.md). It creates restricted
source records and a finite source-quality review queue without performing
inclusion or research coding.
