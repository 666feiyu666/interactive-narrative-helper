# Corpus catalog

Catalog records should contain metadata, provenance, discovery date and method,
inclusion status, rights status, and stable source links. A catalog entry is not
permission to copy or process a full work.

The current frozen itch.io listing is stored under
[`itchio-public-text/`](itchio-public-text/). That directory is a Git-safe
control plane; copied project-page material remains in `restricted-sources/`.
Its entries are discovery candidates rather than confirmed educational-IF
cases.
