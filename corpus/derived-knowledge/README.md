# Derived knowledge

Store traceable Track A design precedents, pattern summaries, or knowledge cards
here. Each item should identify:

- creator-described educational purpose and topic;
- intended audience and application setting when stated;
- interactive narrative form or mechanics;
- the described relationship between interaction and educational intent;
- supporting source annotations and cases;
- relevant variations, applicability conditions, and missing information; and
- the level of researcher normalization or interpretation.

These items support comparison and future retrieval. They document how
creators describe educational IF designs; they do not rank one design as the
correct or universally effective choice.

The current frozen source snapshot is
[`track-a-itchio-v1.1-knowledge-v1/`](track-a-itchio-v1.1-knowledge-v1/). It
contains 122 case-precedent cards—2 complete-core Tier B and 120
partial-substantive Tier C—and a hash-bearing manifest. The cards contain
normalized knowledge only—no descriptions, evidence excerpts, public URLs, or
local source paths. The release is automation-reviewed and suitable for
maintained Track A runtime development, but it is not an independently
human-validated research result. The strict v1.0 two-card release remains
preserved under
[`track-a-itchio-v1.0-knowledge-v1/`](track-a-itchio-v1.0-knowledge-v1/).

The default v0.2 runtime consumes the formal release
[`track-a-educational-design-knowledge-v1/`](track-a-educational-design-knowledge-v1/),
which is deterministically derived from the v1.1 snapshot without reopening
source records or writing the canonical workbook. It contains 6 domain
syntheses, 194 cross-case patterns with at least two supporting cases, and all
122 case design cards. Its manifest records per-file hashes, counts, the source
snapshot hash, an aggregate model-facing hash, and the incomplete human-review
status.

The formal release adds a knowledge organization layer; it does not expand the
source population or convert deterministic patterns into research findings.
