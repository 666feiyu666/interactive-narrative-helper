# Track A itch.io knowledge snapshot v1

This frozen snapshot contains two Tier B `case_precedent` cards promoted from
the strict v1.0 screening run.

- `knowledge-cards.ndjson` is the model-facing runtime input.
- `manifest.json` records rule version, source workbook hashes, artifact hashes,
  counts, review method, and limitations.

The cards contain normalized knowledge only. Source descriptions, evidence
excerpts, URLs, and local paths remain outside the model-facing file. The
snapshot passed a deterministic second-pass audit but has not undergone
independent human double-coding and does not establish learning effectiveness.
