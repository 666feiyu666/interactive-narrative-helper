# Current source-preparation protocols

Two protocols are current:

- itch.io public-page bundle defines the authorized acquisition, restricted
  storage, hashing, and resume contract.
- itch.io offline page cleaning defines the deterministic, network-disabled
  transformation from retained page HTML to source records.

They do not define a screened corpus, a coding method, research findings, or an
Agent knowledge base. Track A screening, coding, analysis, and synthesis
protocols have not yet been designed.
