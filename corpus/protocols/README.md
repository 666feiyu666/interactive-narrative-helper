# Corpus protocols

Protocols in this directory define the current bounded collection and
transformation contracts. They do not constitute numbered experiments or
authorize network collection beyond their stated scope.

- [`itchio-public-page-bundle-v1.0.md`](itchio-public-page-bundle-v1.0.md)
  defines the stable public-page acquisition, restricted storage, hashing, and
  resume contract.
- [`itchio-offline-page-cleaning-v1.0.md`](itchio-offline-page-cleaning-v1.0.md)
  defines the deterministic, network-disabled transformation from retained
  page HTML to reviewable source records.
- [`itchio-track-a-screening-and-coding-v1.0.md`](itchio-track-a-screening-and-coding-v1.0.md)
  defines the first 606-row screening, evidence, rule-audit, and knowledge
  promotion procedure.
- [`itchio-track-a-codebook-v1.0.md`](itchio-track-a-codebook-v1.0.md) defines
  the normalized labels and their evidence conditions.
- [`itchio-track-a-screening-and-coding-v1.1.md`](itchio-track-a-screening-and-coding-v1.1.md)
  separates the conjunctive scope gate from the disjunctive substantive
  knowledge gate and documents the resulting 122-record pool.
- [`itchio-track-a-codebook-v1.1.md`](itchio-track-a-codebook-v1.1.md) preserves
  the label vocabulary while adding missingness, coverage-profile, and Tier C
  rules for partial precedents.

The v1.0 Track A protocol remains preserved as the strict complete-core rule
comparison; v1.1 is the current knowledge-pool procedure.

Superseded development protocols and diagnostic run reports are not retained
once their necessary constraints are represented by the current protocol,
automated tests, and accepted full-run evidence.
