# Corpus protocols

Protocols in this directory define the current bounded collection and
transformation contracts. They do not constitute numbered experiments or
authorize network collection beyond their stated scope.

- [`itchio-public-page-bundle-v1.0.md`](itchio-public-page-bundle-v1.0.md)
  defines the stable public-page acquisition, restricted storage, hashing, and
  resume contract.
- [`itchio-offline-page-cleaning-v1.0.md`](itchio-offline-page-cleaning-v1.0.md)
  defines the deterministic, network-disabled transformation from retained
  page HTML to reviewable source records.

Superseded development protocols and diagnostic run reports are not retained
once their necessary constraints are represented by the current protocol,
automated tests, and accepted full-run evidence.
